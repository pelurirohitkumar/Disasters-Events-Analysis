# Disaster Events Analysis 📊🌍

This repository contains a comprehensive data analysis project focused on disaster events. The project aims to uncover patterns, trends, and insights related to different types of disasters using Python-based analysis and Power BI visualizations.

## 📁 Project Files
- `disaster_Events_2025.csv` - Data set of Disasters Occured upto 2025
- `disaster_analysis.ipynb` – Jupyter Notebook containing data preprocessing, exploratory data analysis (EDA), and visual insights  
- `disaster-events-report.pbix` – Interactive Power BI dashboard for disaster analysis  
- `README.md` – Project documentation  

## 📘 Project Overview

Natural and human-made disasters have significant social, economic, and environmental impacts. This project analyzes disaster event data to better understand:

- Frequency and distribution of disasters  
- Changes in disaster patterns over time  
- Impact differences across regions  
- Most common and most severe disaster types  

The notebook is structured with clear markdown explanations, making the analysis easy to follow and reproducible.

## 🔍 Analysis Performed

- Data cleaning and preprocessing  
- Handling missing and inconsistent values  
- Exploratory Data Analysis (EDA)  
- Year-wise and region-wise trend analysis  
- Disaster type comparison  
- Visual analysis using charts and graphs  

## 📊 Power BI Dashboard

The Power BI report provides:

- Interactive filters by year, region, and disaster type  
- Summary metrics and key indicators  
- Visual comparison of disaster impacts  
- Easy-to-understand dashboards for presentations and reporting  

> **Note:** Microsoft Power BI Desktop is required to open `.pbix` files.

## 📌 Key Insights & Outcomes
